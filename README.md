# How Do Online Reviews of Consumer Tech Products Correlate with Sales Performance?

_A data science research project investigating the relationship between customer reviews and sales performance for consumer tech products (desktops, laptops, and phones) across Best Buy and Newegg._

---

## Part 1: Project Proposal
**Objective:** Define the research question

_Do customer ratings and review sentiment for consumer tech products have a measurable impact on their sales performance?_

## Part 2: Complex Messy Data
**Objective:** Collect, clean, and prepare raw data for analysis.

Scraped and aggregated product data from the "Best Sellers" category for [Best Buy](https://www.bestbuy.com) and [Newegg](https://www.newegg.com) across three categories (desktops, laptops, phones) using web scraping and API interactions. Data includes customer reviews, ratings, review counts, pricing, and product metadata. Performed extensive data cleaning and preprocessing to handle missing values, inconsistent formats, and merged data from multiple sources into unified datasets. Generated cleaned CSV files and JSON data structures for downstream analysis.

[See All Collected json/csv Data](/Part2%20-%20Complex%20Messy%20Data/)
